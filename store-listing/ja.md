## Description
Snook Legend は、本気でビリヤードをしたい人のための3Dエイトボールゲームです。すべてのショットが物理法則どおりに動き、ボールは本物のように転がり、サイドポケットは開いた形なので、運よりも腕がものを言います。

キューを思いどおりに操れます。狙いを定め、強さを選び、タップが手球のどこを撞くかを正確に決め、キューの角度はショットを横から見た画面でキューをドラッグして立てます。画面に数字は出ません。本物のテーブルと同じように、強さも角度も目で判断します。引き球、押し球、ひねり、ジャンプ、マッセも自在です。

【オンライン】
ロビーに入ってチャットしたり、誰かを招待したり、「今すぐ対戦」で自分と同じくらいの腕前の相手を見つけたりできます。レート戦とカジュアル戦、オープンテーブル（公開またはパスワード付き）、勝ち上がり表がリアルタイムで更新される4・8・16人のトーナメント、フレンド、1手番につき最大3日のデイリー対戦、そして世界ランキング。64種類のプロフィール画像から1枚と、あなたの国を選べます。

【コンピューター対戦】
それぞれ独自のスタイルと個性を持つ15人の対戦相手。まだ勉強中のLeoからチャンピオンのViktorまで、その間には毎ショットにすべてを賭けるTitoや、決して外さないYuriもいます。彼らはプレイしながら試合について話します（オフにもできます）。ツアーで15人全員に勝てば限定キューを獲得。彼らとのトーナメント（16人のノックアウトかポイント制のアリーナ）や、フレンドのスタイルでプレイする「ゴースト」との対戦も楽しめます。

【毎日、新しい挑戦】
デイリーチャレンジでは全員が同じ配置に挑み、その日のランキングが出ます。星が付くドリルで、ポケットの腕、ひねり、バンクを測れます。どの対戦でも、アカウントのレベルを上げる経験値が手に入ります。

【あなたのスタイル】
キュー、ラシャ、チョーク、ボールセット、テーマ付きのテーブルとホール。すべてプレイで獲得したコインで手に入ります。キューは、そのキューで勝つほどリングや象嵌が加わっていきます。

【見やすさにこだわって】
むらなく照らされたテーブル、いつでも番号が読めるボール、やわらかな影。各プレイヤーのボールを沈めた順に表示するスコアパネル。上から見てプレイしたいですか？ カメラをトップビューに固定するオプションがあります。古いノートPCからゲーミングPCまで、ほぼどんなPCでも動き、グラフィックは「低」から「ウルトラ」まで選べます。

【2つのルール】
バーやビリヤード場でおなじみのブラジルルールは、ペナルティボールありです（ファウルすると手番が移り、相手の番号の小さいボールがテーブルから取り除かれます）。国際大会で使われるWPAの公式ルールでは、自分のグループのボールはどのポケットに入れても有効、8番はポケットをコール（ポケットをクリック）し、ファウルの後はテーブルのどこにでも置けるフリーボールになります。ルールごとにレートと世界ランキングがあり、いつでも切り替えられます。詳しいルールは、メニューからも対戦中でも、クリックひとつで確認できます。

## Features
- サイドポケットが開いた8フィートのテーブルと、リアルな物理
- ひねり、引き球、押し球、マッセ、ジャンプショット
- 目で狙う：横から見た画面でキューの角度を調整、画面に数字なし
- オンラインのレート戦とカジュアル戦、世界ランキング付き
- 勝ち上がり表がリアルタイムで更新される4・8・16人のトーナメント
- チャット、フレンド、招待、公開またはパスワード付きのテーブルがそろったロビー
- デイリー対戦：自分の手番まで最大3日
- 個性豊かで、試合について話す15人のコンピューター対戦相手
- ツアー：15人全員に勝って限定キューを獲得
- その日のランキング付きデイリーチャレンジ
- それぞれ最大3つ星の24種類のドリル
- アカウントのレベル、実績、トロフィー棚、64種類のプロフィール画像
- プレイで手に入るキュー、ラシャ、テーブル、テーマ付きのホール
- 各プレイヤーのボールを沈めた順に表示するスコアパネル
- 見やすさにこだわった画面、トップビューだけでプレイするオプションも
- グラフィックは「低」から「ウルトラ」まで：古いPCでも動き、新しいPCでは美しく
- ブラジルルールか公式（WPA）ルール、それぞれ専用のレートとランキング、いつでも切り替え
- 英語から中国語、アラビア語、ヒンディー語まで27言語に対応
